# ЛР №5 — Simon («Симон говорит»)
Четыре цветные кнопки, показ последовательности через `setTimeout`, проверка ввода, уровни, завершение и корректный перезапуск; звук Web Audio включается по желанию.
Запуск: открыть `/task5/` через GitHub Pages или выполнить `python3 -m http.server 8000` в корне репозитория и перейти на `http://localhost:8000/task5/`. Тесты: `node --test task5/model.test.mjs` из корня репозитория.
