# ЛР №5 — Simon («Симон говорит»)
Игра с четырьмя цветными кнопками и последовательностью через `setTimeout`: проверка порядка нажатий, уровни, завершение при ошибке и корректный перезапуск. Новый адаптивный дизайн в стиле яркого аркадного плаката, звук Web Audio — по желанию.
Запуск: из корня репозитория `python3 -m http.server 8000`, затем открыть `http://localhost:8000/task5/` (или разместить `task5/` на GitHub Pages). Проверка логики: `node --test task5/model.test.mjs`.
