# Лабораторная №8 — Saldo

Учёт личных финансов: добавление, просмотр, редактирование и удаление операций через `json-server`; категории загружаются с сервера, сводка пересчитывается автоматически. Проект разделён на API (`api.js`), интерфейс (`ui.js`) и управление событиями (`script.js`).

## Запуск

1. В первом терминале перейдите в папку `task8` и запустите API: `npx json-server@0.17.4 --watch db.json --port 3001`.
2. Во втором терминале из **корня репозитория** выполните `python -m http.server 8000` (Windows: `py -m http.server 8000`).
3. Откройте в браузере `http://localhost:8000/task8/`.

Для первой команды нужен Node.js и доступ к npm (при первом запуске `npx` скачает `json-server`). Данные сохраняются в `db.json`; для сброса тестовых данных восстановите исходный файл. Фронтенд с ES-модулями нужно открывать через локальный HTTP-сервер, а не `file://`. При публикации фронтенда на GitHub Pages API на `localhost:3001` будет доступен только на компьютере, где запущен `json-server`.

## Архитектура

- `api.js` — функции `fetch` (GET, POST, PATCH, DELETE), проверка `response.ok`, обработка ошибок в `try/catch`.
- `ui.js` — DOM, карточки, итоги, форма, уведомления.
- `script.js` — состояние приложения, обработчики событий, вызовы API.
- `db.json` — категории и несколько тестовых операций.

В этой лабораторной реализована **часть 1 (№8)**. Фильтрация, пользовательские категории и `localStorage` относятся к лабораторной №9.
