# Лабораторная работа №8–9 — Todo-list на React

Список задач с добавлением (в том числе выполненных), удалением, переключением статуса, фильтрацией, сортировкой, счётчиками и сохранением в localStorage. Компоненты и вспомогательные функции разделены; `memo`, `useMemo` и `useCallback` уменьшают лишние рендеры. Дополнительно реализован импорт первых 20 задач из JSONPlaceholder без дублирования существующих идентификаторов.

## Запуск

Требуется Node.js 20 или 22 (рекомендуется 22). Из папки `task8-9`:

```sh
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173). Сборка: `npm run build`, просмотр сборки: `npm run preview`. Проверка чистых функций: `npm test`.

## Структура и оптимизация

- `App.jsx` хранит задачи, фильтр и сортировку; передаёт данные и обработчики через props.
- `components/` содержит отдельные функциональные компоненты. Ввод текста локален в `TodoForm`, поэтому при печати `App` и список не рендерятся. `TodoItem` получает задачу через props; отдельный state ему не требуется.
- `utils/todos.js` содержит операции над массивом, валидацию и конфигурацию фильтров/сортировок. Чтобы добавить новый фильтр или сортировку, добавьте запись в `FILTERS` или `SORTS` соответственно.
- `utils/storage.js` восстанавливает задачи ленивой инициализацией состояния. `useEffect` в `App` сохраняет их при изменении. `utils/api.js` отвечает за импорт. Для импортированных задач используется дата импорта, поскольку API не возвращает дату создания.
- `useMemo` пересчитывает отображаемые задачи и статистику только при изменении зависимостей. `useCallback` сохраняет ссылки на обработчики. `memo(TodoItem)` пропускает рендер неизменённых задач, так как при переключении статуса создаётся новый объект только для выбранной задачи.

Для проверки оптимизации можно записать действия в React DevTools Profiler: ввод текста в форму и переключение одного чекбокса. В режиме разработки StrictMode может намеренно вызывать функции рендера повторно.

Основные задания обеих частей выполнены в одном проекте. Необязательный локальный json-server не используется; фильтрация и сортировка клиентские. Для импорта из внешнего API требуется интернет, остальные функции работают локально.
