# Лабораторная №6 — «Змейка»

Игра на Canvas: стрелки — управление, яблоки увеличивают счёт и длину, столкновение завершает игру, кнопка перезапускает её.
Запуск из папки `task6`: `python -m http.server 8000`, затем открыть `http://localhost:8000/` (также работает на GitHub Pages).
Структура: `game.js` — правила и состояние, `render.js` — Canvas, `script.js` — ввод и игровой цикл.
