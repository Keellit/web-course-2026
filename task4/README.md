# ЛР №4 — «Быки и коровы»
Игра на чистом JavaScript: валидация числа, подсчёт быков и коров, история и перезапуск; логика, интерфейс и контроллер разделены.
Запуск: открыть `/task4/` через GitHub Pages или выполнить `python3 -m http.server 8000` в корне репозитория и перейти на `http://localhost:8000/task4/` (для ES-модулей нужен HTTP). Тесты: `node --test task4/model.test.mjs` из корня репозитория.
