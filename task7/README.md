# Лабораторная №7 — лента постов
Посты загружаются по 10 из JSONPlaceholder при прокрутке; поиск по заголовкам с задержкой 300 мс, сообщения о загрузке и ошибках.
Модули: `api.js` — запросы, `ui.js` — отрисовка, `script.js` — состояние и события. Запуск из корня репозитория: `python -m http.server 8000`, затем `http://localhost:8000/task7/`.
