# Лабораторная работа №7 — POSTROOM

Бесконечная лента постов из JSONPlaceholder: загрузка по 10 записей, поиск по заголовкам с задержкой 300 мс, индикатор загрузки и обработка сетевых ошибок.
Код разделён по слоям: `api.js` — запросы, `store.js` — данные и фильтрация, `ui.js` — карточки и интерфейс, `script.js` — события и управление.
Для запуска из корня репозитория выполните `python -m http.server 8000` и откройте `http://localhost:8000/task7/` (либо разместите папку на GitHub Pages). Нужен доступ к интернету.
